# 🍜 班级美食地图

一个展示校园周边美食的趣味主题展示站。

## 🌐 在线访问

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Deployed-green)](https://fghfjg.github.io/fun-theme-showcase/)

**点击访问网站：** [https://fghfjg.github.io/fun-theme-showcase/](https://fghfjg.github.io/fun-theme-showcase/)

## ✨ 功能特色

| 功能 | 描述 |
|------|------|
| 🍽️ **美食展示** | 12条精选美食内容，涵盖全国各地特色美食 |
| 🏷️ **分类筛选** | 支持按类别（面条、小吃、早点、夜宵）筛选 |
| ❤️ **点赞功能** | 为喜欢的美食点赞，数据本地持久化 |
| ⭐ **五星评分** | 为美食打分，显示平均分 |
| 💬 **留言板** | 访客可提交留言，显示最近10条 |
| 🖼️ **图片查看** | Lightbox图片放大查看，支持左右切换 |
| 🚀 **懒加载** | 图片滚动到可视区域才加载 |
| 📤 **分享功能** | 一键分享网站链接 |
| ⬆️ **返回顶部** | 滚动超过一屏显示返回按钮 |
| 📊 **进度条** | 顶部显示页面滚动进度 |

## 📁 项目结构

```
fun-theme-showcase/
├── index.html      # 主展示页面

```

## 🛠️ 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式设计
- **JavaScript** - 交互逻辑
- **Tailwind CSS** - 快速样式开发
- **GitHub Pages** - 网站部署

## 📱 响应式设计

支持手机、平板、桌面端访问，移动端图片比例合适，触摸屏可滑动切换图片。
