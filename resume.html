👤 个人简介

大家好，我是一名来自2026届的美食爱好者，也是"班级美食地图"网站的站长 👋

作为一名资深干饭人，我始终相信：美食是连接人与人之间最温暖的纽带。这个网站诞生于第三次网页开发课程，旨在记录和分享我们身边那些藏在街巷里的宝藏美食。

从热气腾腾的面条到香气四溢的小吃，从早餐的一盅两件到夜宵的火锅串串，每一道美食背后都有属于它的故事。我希望通过这个平台，让更多人发现身边的美味，也欢迎大家留言分享你的美食发现！

🛠️ 技能标签

HTML5 CSS3 JavaScript Tailwind CSS Vue.js React Node.js Git GitHub Pages 响应式设计 本地存储

🍜 项目介绍

主题选择原因

🍽️ 民以食为天 — 美食是每个人都感兴趣的话题，尤其是对于学生群体来说，校园周边的美食总是充满了回忆和故事。

🎯 实用性强 — 作为一个美食分享平台，不仅可以展示网页开发技能，还能真正帮助同学们发现身边的宝藏店铺。

💡 技术挑战 — 从地图展示到用户交互，从图片处理到数据存储，美食主题可以很好地串联起各种前端技术点。
